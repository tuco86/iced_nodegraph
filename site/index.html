iced_nodegraph

A node graph editor widget for iced

crates.io docs.rs GitHub

Start here

  1. Quick Start – nodes, pins and one edge inside a view, with the callbacks that report intent.
  2. What the host owns – the widget is stateless between frames and never mutates your data model.
  3. Ids – nodes, pins, edges and anchors carry your own id types, and a pin can carry a payload.
  4. Styling – node, edge and pin styles are flat concrete structs, overridden with struct-update over a theme-derived default.
  5. Interaction – connections behave like physical plugs: a dragged edge snaps to a compatible pin and reports the connection immediately.
  6. Coordinates – screen space and world space are distinct euclid types, so mixing them is a compile error.

Demos

  • hello_world

    The most feature-complete demo. A pre-built workflow graph with a command palette (Cmd/Ctrl+Space), 22 theme presets, live style-config nodes, selection, clone, delete, group move, edge cutting, and native persistence.

    Open Source

  • styling

    Visual customization and theming. Node presets, theme switching, and live style controls (corner radius, opacity, border width) applied to the selection.

    Open Source

  • interaction

    Typed pin connection validation: input-only, output-only, and bidirectional pins; type compatibility; single-connection and duplicate rules; self-loop rejection; and live snap feedback.

    Open Source

  • 500_nodes

    Performance benchmark with a procedurally generated graph of 500+ nodes. A toggleable stats overlay reports per-frame op timings and node/pin/edge counts with cull rates.

    Open Source

  • shader_editor

    Visual WGSL shader graph with a category-grouped command palette, typed sockets, and a compiler that validates the graph and generates WGSL.

    Open Source
